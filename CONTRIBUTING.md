# Contributing

Thanks for your interest in contributing! Please follow these simple rules:

- Open an issue before starting significant work so we can discuss implementation details.
- Fork the repo and create a feature branch for pull requests (branch names prefixed with `feature/`).
- Keep changes small and focused, and include tests or documentation updates for code changes.
- All pull requests should include a short description of the changes and any required setup steps.
